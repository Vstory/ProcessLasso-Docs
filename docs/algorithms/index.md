# Algorithms

- **[Performance Mode](performance-mode.md#gaming_mode)** — Adjust the system to maximize performance when certain applications are run.
- **[ProBalance](probalance.md)** — ProBalance is our famously efficacious algorithm to maintain PC responsive during high CPU loads.
- **[CPU Limiter](cpu-limiter.md#cpulimiter)** — Dynamically, temporarily limit CPU utilization of a process when it reaches a threshold.
- **[Startup Boost](../rules/startup-boost.md#startup_boost)** — Temporarily raise the priority class of processes for a period of time after they are started.
- **[Instance Balancer](instance-balancer.md#instancebalancer)** — Spread CPU cores among running instances of application(s).
- **[Instance Count Limits](../rules/instance-limits.md#instance_count_limits)** — Limit the number of instances a process may have in a user session.
- **[Group Extender](group-extender.md#groupextend)** — Enable processor group unaware applications to make full use of the CPU.
- **[SmartTrim](https://bitsum.com/smarttrim/)** — Periodically trim working sets of high memory consuming processes and/or clear the system standby list (cache).
