# IdleSaver

- *Menu path: ‘Options / Power/ IdleSaver …’*

IdleSaver enables users to configure a power plan specifically for times when the system is idle. This feature allows users to utilize a high-performance power plan during active periods without entirely forgoing energy savings, as the system automatically switches to a more conservative power plan when the user is idle.
