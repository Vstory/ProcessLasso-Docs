# Auto-Terminate List

- *Menu path: ‘Options / Control / Disallowed Processes …’*

The processes listed here will get terminated when they are found to be running. Process Lasso cannot (at present) actually prevent them from trying to start up, it just immediately terminates them when it finds them running.
