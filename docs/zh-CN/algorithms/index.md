# 算法

- **[性能模式](performance-mode.md#gaming_mode)** — 在运行特定应用程序时调整系统以获得最大性能。
- **[ProBalance](probalance.md)** — ProBalance 是我们广受好评的算法，用于在高 CPU 负载下保持电脑的响应能力。
- **[CPU 限制器](cpu-limiter.md#cpulimiter)** — 当进程的 CPU 使用率达到阈值时，动态、临时地限制它。
- **[启动提升](../rules/startup-boost.md#startup_boost)** — 在进程启动后的一段时间内临时提高其优先级类别。
- **[实例均衡器](instance-balancer.md#instancebalancer)** — 在应用程序的多个运行实例之间分配 CPU 核心。
- **[实例数量限制](../rules/instance-limits.md#instance_count_limits)** — 限制某个进程在用户会话中可拥有的实例数量。
- **[组扩展器](group-extender.md#groupextend)** — 让不支持处理器组的应用程序也能充分利用 CPU。
- **[智能内存整理](https://bitsum.com/smarttrim/)** — 定期整理高内存消耗进程的工作集，和/或清除系统待机列表（缓存）。
