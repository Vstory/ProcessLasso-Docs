# 智能内存整理

*若需总体介绍，包括智能内存整理不是什么，以及针对 16 GB 与 32 GB 系统的建议设置，请参阅 [智能内存整理：Process Lasso 的内存整理功能详解](https://bitsum.com/smarttrim/)。*

- *菜单路径：「选项 / 内存 / 智能内存整理选项 …」*

智能内存整理是一种智能内存管理算法，可以在达到阈值时按进程整理工作集，也可以清除系统待机列表（缓存）。
