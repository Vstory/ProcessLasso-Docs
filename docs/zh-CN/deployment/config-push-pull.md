# 推送或拉取配置与日志

把 Process Lasso 配置更改推送到本地机器存储时，建议使用脚本或其他自动化手段把 Process Lasso 配置文件复制到目标机器。配置文件一旦被覆盖，Process Lasso 就会采用它（无需重启应用）。反过来，配置文件也可以由终端设备主动拉取。同样，日志文件也可以从设备定期拉取。
