# 部署

Process Lasso 在 Windows Server 上表现出色，包括远程桌面服务（终端服务）。它可以防止单个用户或进程独占服务器的 CPU 资源、改善响应能力，并让您完全掌控正在运行的进程。核心引擎（Governor）与图形界面相互独立，因此安装后无需对最终用户可见。服务器用途请使用独立的 Process Lasso 服务器版，它提供 30 天免费试用。更多信息见[此页面](https://www.bitsum.com/server/)。

关于许可证类型与条款（包括虚拟机与远程桌面服务），见[许可](licensing.md)。
