# 许可

Process Lasso 可免费使用。Pro 功能在试用期结束后需要许可证。免费版与 Pro 版的差异及价格列在 [Process Lasso 免费版与 Pro 版对比](https://bitsum.com/process-lasso-free-vs-pro/)页面。许可证在[获取 Process Lasso Pro](https://bitsum.com/get-lasso-pro/)与[批量包](https://bitsum.com/get-process-lasso-pro-volume/)页面销售。

<a id="license-types"></a>

## 许可证类型

| 许可证 | 覆盖范围 | 用途 |
| --- | --- | --- |
| 单机 | 每份许可证对应一台电脑。数量可在结账时设置。 | 家庭或商业 |
| 全家庭版 | 一个家庭内最多 5 台电脑 | 仅限非商业用途 |
| 批量包 | 每包 5、25、50 或 100 台电脑 | 家庭或商业 |

您可以向购物车添加多个批量包以达到所需数量。购买后我们可以拆分或合并许可证包，只需[联系我们](https://bitsum.com/contact/)。

<a id="terms"></a>

## 条款

- **月度**与**年度**许可是循环订阅，您可以随时从[我的许可证](https://bitsum.com/checkout/purchase-confirmation/purchase-history/)页面或[联系我们](https://bitsum.com/contact/)取消。
- **终身**许可为一次性付费，包含所有小版本与大版本更新。
- **全家庭版**许可面向同一家庭内最多 5 台电脑，仅限非商业用途。笔记本电脑及其他便携设备可以外出携带，只要它们属于该家庭。许可证不得与不住在该家庭的亲友共享。商业用户请改买 [5 机批量包](https://bitsum.com/get-process-lasso-pro-volume/)。
- **新电脑：** 只要同时使用的许可证数量不超过您购买的数量，您可以随时通过重新激活产品把许可证迁移到新电脑或新的 Windows 安装上。
- **虚拟机**与物理机按相同方式许可。
- **虚拟桌面环境与远程桌面服务（RDS）**必须按最大并发用户数购买许可。
- **商业用途**须在部署后 30 天内购买。
- **退款：** 若您不满意，在任何付款后 30 天内可获全额退款。

完整条款见[最终用户许可协议](https://bitsum.com/terms-of-use/)。若需定制报价或许可方面的疑问，请[联系我们](https://bitsum.com/contact/)。
