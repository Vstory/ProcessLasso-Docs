# 介绍

Process Lasso 是一款 Windows 进程自动化与优化软件。从 [ProBalance](algorithms/probalance.md) 这类调节算法，到用户自建的规则与持久设置（例如 [CPU 相关性](rules/cpu-affinities.md) 和 [优先级类别](rules/priorities.md)），Process Lasso 让您完全掌控正在运行的应用程序！

[下载 Process Lasso](https://bitsum.com/download-process-lasso/)

我们广为人知的 ProBalance 算法能在高 CPU 负载下维持系统响应能力。该专有算法会动态调整正在运行的程序的优先级，使部分程序获得比其它程序更高的 CPU 访问优先级。有了 ProBalance，无论是单个还是多个进程，都无法再把您的系统拖入近乎停滞的状态。即便在沉重的 CPU 负载之下，Process Lasso 也能让您继续与电脑交互。您可以用我们的 [CPUEater 演示](https://bitsum.com/how-probalance-works/#cpueater) 亲自体验 ProBalance，或阅读 [ProBalance 如何保持 Windows 响应能力](https://bitsum.com/how-probalance-works/)。

功能概览：[ProBalance](https://bitsum.com/how-probalance-works/)、[性能模式](https://bitsum.com/bhp/)、[智能内存整理](https://bitsum.com/smarttrim/)，以及 [CPU 限制器](https://bitsum.com/docs/limiting-cpu-use-with-process-lasso-cpu-limiter/)。

Process Lasso 还通过一系列独特而实用的功能，让用户自动化并调整应用程序的运行方式。这些功能包括持久的优先级类别、持久的 CPU 相关性、不允许的进程、每进程电源计划、用于高级规则的进程看门狗、进程实例数量限制、实例均衡或应用均衡等等！这些功能让您能够依据自动应用的设置，控制程序如何使用电脑的资源。有了 Process Lasso，您可以精确决定进程应当如何运行。

此外还提供许多附加功能，例如电源计划自动化、系统响应能力指标和进程活动日志记录。

为把资源占用降到最低，所有算法和进程规则都由一个名为 Process Governor 的独立后台服务强制执行。图形界面完全是可选的。
