# Process Lasso 规则列

<a id="rules"></a>

#### 规则

进程列表中的「规则」列以简写形式表示每个进程已设置的规则。将鼠标悬停在「规则」列标题上可查看快捷图例。

格式：`[E|e][+|-][S][^][_][X][L][W][g][K][d][D][x][t][f][ic|ih|in|il|ib][(GPU..)][R|H|A|N|B|I][p][< to <<<<][affinity][(CPU sets)][M0-M7][#n]`

符号按所列顺序出现。

| 字符 | 含义 |
| --- | --- |
| E | 效率模式：开启 |
| e | 效率模式：关闭 |
| + | 线程优先级提升规则：已启用 |
| – | 线程优先级提升规则：已禁用 |
| S | 启动提升规则 |
| ^ | 已跨处理器组扩展（组扩展器） |
| \_ | 实例均衡器规则 |
| X | 已从 ProBalance 抑制中排除 |
| L | CPU 限制器规则 |
| W | 已设置看门狗规则 |
| g | 归类为游戏（触发性能模式） |
| K | 保持运行（终止后重启） |
| d | 运行期间阻止电脑睡眠 |
| D | 运行期间阻止显示器睡眠 |
| x | 已从前台提升排除 |
| t | 已从智能内存整理排除 |
| f | 已从空闲节能排除（此进程运行时空闲节能不会介入） |
| ic | I/O 优先级类别：关键 |
| ih | I/O 优先级类别：高 |
| in | I/O 优先级类别：正常 |
| il | I/O 优先级类别：低 |
| ib | I/O 优先级类别：很低（后台） |
| (GPU..) | GPU 规则，见下文 |
| R | 优先级类别：实时 |
| H | 优先级类别：高 |
| A | 优先级类别：高于正常 |
| N | 优先级类别：正常 |
| B | 优先级类别：低于正常 |
| I | 优先级类别：空闲 |
| p | 运行期间切换到特定电源计划 |
| < | 硬性节流：最低 |
| << | 硬性节流：低 |
| <<< | 硬性节流：中等 |
| <<<< | 硬性节流：高 |
| 0,1,.. | CPU 相关性（CPU 索引列表） |
| (0,1,..) | CPU 集，以圆括号显示 |
| M0-M7 | 默认内存优先级（0 至 7） |
| #n | 实例数量限制为 n，例如 #2 表示限制为 2 |

<a id="gpu-rules"></a>

## GPU 规则

当设置了 GPU 适配器偏好和/或 GPU 调度优先级规则时，它会以圆括号形式显示在 `GPU` 前缀之后。先是适配器偏好符号，随后是调度优先级代码，例如 `(GPU+H)` 表示高性能适配器且调度优先级为高。

| 符号 | 适配器偏好 |
| --- | --- |
| + | 高性能 |
| – | 节能 |
| / | 系统默认 |

| 代码 | GPU 调度优先级 |
| --- | --- |
| RT | 实时 |
| H | 高 |
| AN | 高于正常 |
| N | 正常 |
| BN | 低于正常 |
| I | 空闲 |
