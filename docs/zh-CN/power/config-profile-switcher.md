# 配置方案切换器

- *菜单路径：「文件 / 配置方案 / 配置方案切换器 / 配置规则…」*

配置方案是所有进程规则与设置的命名集合。这使用户可以为特定工作负载建立多套规则，例如「游戏」与「办公」。此前这些配置方案的用处有限，因为它们无法在运行某个特定进程时自动切换过去。

配置方案切换器填补了这一空白：在指定进程运行时切换配置方案，匹配的进程随后终止时恢复先前的配置方案。每个配置方案都应当包含用于撤销其他方案所做更改的规则，例如把 CPU 相关性恢复为所有核心。

该功能应谨慎使用。如果有多个同时运行的进程分别匹配不同的配置切换规则，只有最早的那个进程的配置会被执行。

请注意，先前活动配置方案中的进程更改不会自动撤销。您必须在其他配置方案中创建规则来抵消之前的更改。例如，若某个方案更改了 notepad.exe 的 CPU 相关性，则其他方案必须包含相应的 CPU 相关性规则（如果需要）来撤销该更改。

配置方案切换器支持通配符与高级[进程匹配规则](../reference/process-matching.md#processmatch)。

对话框顶部的「*启用配置方案切换器*」复选框，或配置方案切换器子菜单中的「*启用*」项（系统托盘菜单中同样可用），可以在不删除任何规则的前提下开关该功能。取消勾选时，规则会保留但不生效；如果某条规则此前已切换过配置方案，则恢复先前的方案。切换器默认启用。
