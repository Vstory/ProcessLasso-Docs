# 基于负载的电源计划切换器

- *菜单路径：「选项 / 电源 / 基于负载的电源计划切换器…」*

基于负载的电源计划切换器根据系统总 CPU 负载自动切换当前的 Windows 电源计划。当持续 CPU 负载升过您设置的阈值时，它会切换到高性能电源计划；当负载回落时，又退回更经济的计划。这让您的电脑大多数时间处于节能状态，却能在繁重负载出现的瞬间自动切入高性能，无需手动切换。

![](../../media/load-based-power-switcher.png)

基于负载的电源计划切换器

为避免来回快速切换（震荡），切换器不会对瞬时 CPU 尖峰作出反应，而是对平滑后的平均值、并保证两次切换之间的最小间隔后再评估。

该功能由 Process Lasso 核心引擎（Governor）管理，因此即使 GUI 关闭也能工作。

<a id="options"></a>

## 选项

**启用基于负载的电源计划切换器**
该功能的总开关。禁用时（或 Process Lasso 退出时），切换器所做的任何电源计划更改都会被还原。

**高负载电源计划**
平滑后 CPU 负载达到高阈值时激活的电源计划。通常是*高性能*或*Bitsum 最高性能*。

**低负载电源计划**
平滑后 CPU 负载低于低阈值时激活的电源计划。通常是*平衡*。该选择仅在勾选「强制使用低负载电源计划」时生效（见下文）。

**高 CPU 负载阈值（%）**（默认：50）
当平滑后 CPU 负载达到或超过该百分比时，切换器启用高负载计划。

**低 CPU 负载阈值（%）**（默认：10）
当平滑后 CPU 负载低于该百分比时，切换器退回低负载。高阈值必须大于低阈值；两者之间的间隔构成不进行任何切换的缓冲带。

**平滑窗口（采样数）**
在与阈值比较之前进行平均的近期 CPU 负载采样数。每个引擎刷新周期采样一次（默认引擎更新速度下为每秒一次），因此默认值 5 意味着切换决策基于大约最近 5 秒的 CPU 负载，而不是某个瞬间。

取值越大，切换器越能抵御短暂的 CPU 尖峰与跌落，代价是对真实负载变化的反应更慢。取值越小则反应更快，但可能切换更频繁。取值为 1 会完全禁用平滑，决策直接基于瞬时 CPU 负载。

**在电源计划中的最短时间（ms）**（默认：5000）
一次切换之后，必须经过的最短时间才允许再次切换。这与平滑窗口互为补充：平滑过滤的是 CPU 负载信号本身，而该设置限制的是切换发生的频率。

**强制使用低负载电源计划**
控制负载消退时的行为：

- *未勾选*（默认）：切换器只管理高负载计划。当 CPU 负载低于低阈值时，它恢复切换之前处于活动状态的电源计划，然后释放控制权，好让其他 Process Lasso 电源功能（例如空闲节能、每进程电源计划）正常工作。
- *勾选*：只要负载低于低阈值，切换器就主动强制使用您选定的低负载计划，在双向都完全接管电源计划。

**记录电源计划更改**
勾选后，切换器所做的每次电源计划更改都会记入 Process Lasso 日志。

<a id="interaction-with-other-power-features"></a>

## 与其他电源功能的交互

当切换器维持高负载计划时，它优先于空闲节能、性能模式和应用电源计划，以免它们争抢当前计划。在默认（不强制）模式下，切换器一旦退回低负载，这些功能就会重新获得控制权。
