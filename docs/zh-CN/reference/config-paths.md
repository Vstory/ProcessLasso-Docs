# 配置与日志路径

在第二个对话框中给出的配置与日志路径设置里，用户可以选择使用集中式的网络配置与日志存储、按机器存储，或按用户存储。

**方案 1：集中式配置与日志** 在这种模式下，所有工作站都被配置为二者之一：(1) 使用托管在网络共享上的集中式配置与日志路径；或 *(2)* 使用机器本地的配置和/或日志路径，但在集中式 INI 配置文件发生变化时把它推送到客户端，并定期从客户端拉取日志。若 INI 配置路径是网络共享，则至少每分钟轮询一次变更；对于本地路径，则使用文件系统变更事件获取通知，因此无需轮询，变更会立即被捕获。

**方案 2：按工作站的配置文件与日志** 在这种模式下，您会在每个工作站上安装 Process Lasso，并使用系统中所有用户都会访问的公共配置与日志路径。

**方案 3：上述方案的某种组合，或其他方法** 归根结底，您可以按几乎任何想要的方式使用 Process Lasso。例如，您可以让工作站从网络共享运行它，而无需在这些工作站上安装 Process Lasso。
