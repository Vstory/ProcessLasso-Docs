# 阻止睡眠的进程

- *菜单路径：「选项 / 电源 / 保持唤醒 …」*

用户可以把进程加入「阻止睡眠」列表，从而阻止电脑与显示器进入睡眠或休眠状态。可以右键单击进程使用「运行时」菜单，或使用应用程序菜单中的「选项 / 配置阻止睡眠的进程 …」。
