# 实例数量限制

- *菜单路径：「选项 / 控制 / 实例数量限制 …」*

用户可以在此对话框中限制某个进程（按用户会话）允许同时运行的实例数量。如果进程匹配这里的某个模式，且已有实例数量等于或超过实例数量限制，新启动的实例将被终止。
