# 启动提升

- *菜单路径：「选项 / CPU / 启动提升…」*

启动提升会在匹配的进程启动后的一段时间内临时提高其优先级类别。这让新进程在加载期间获得短暂的调度优势，改善那些在启动时做大量工作的应用程序的启动响应。

每条规则由以下内容组成：

- **进程匹配**：规则适用的进程。与其他规则一样支持通配符与正则表达式。参见 [进程匹配](../reference/process-matching.md#processmatch)。
- **提升优先级类别**：提升期间施加的优先级类别，可选*高于正常*或*高*。
- **提升持续秒数**：提升持续多久，从 1 到 3600 秒。
- **提升期间禁用效率模式**：勾选后，进程在提升期间会关闭[效率模式](efficiency-mode.md#efficiency_mode)，以免加载时被约束到能效核上。

提升期结束后，进程的优先级类别会恢复到先前的值。若提升生效期间优先级类别被其他因素改变，则保持原样。

您也可以在进程列表中右键单击特定进程，选择「更多 / 启动提升…」来创建启动提升规则。

![启动提升规则对话框](../../media/startup-boost.png)

带有启动提升规则的进程会在[规则列](../interface/rules-column.md)中显示「S」。提升活动会以「启动提升已应用」与「启动提升已结束」事件记录到[日志](../interface/logging.md)中。这些条目可以通过 **选项 > 日志 > 记录启动提升** 一并关闭。
